# Google Apps Script: синхронизация Notes с Google Drive

Скрипт хранит файлы заметок в папке `Notes Sync` на Google Drive владельца
скрипта. PWA общается с ним через iframe-мост `Bridge.html`, поэтому CORS
не требуется.

## Развёртывание

1. Откройте [script.google.com](https://script.google.com/) и создайте новый
   проект.
2. Перенесите в проект:
   - `Code.gs` — серверные функции;
   - `Bridge.html` — мост для `google.script.run`;
   - `appsscript.json` — манифест (можно добавить через «Настройки проекта →
     Показывать файл манифеста»).
3. В «Настройках проекта → Свойства скрипта» создайте свойство:
   - `SYNC_TOKEN` — длинная случайная строка (например, UUID).
   Либо запустите функцию `setupSync()` и скопируйте токен из журнала.
4. Разверните: **Развернуть → Новое развёртывание → Web App**.
   - Execute as: **Me**
   - Who has access: **Anyone**
5. Скопируйте URL вида
   `https://script.google.com/macros/s/.../exec`.

## Подключение в приложении

В приложении откройте меню «⋯» → «Ввести токен доступа» и укажите URL и токен.

Либо передайте параметры ссылкой:

```text
https://your-notes.example/?drive_token=TOKEN&drive_url=https://script.google.com/macros/s/.../exec
```

После открытия токен сохраняется в браузере и удаляется из адресной строки.

## Удаление

Удаление архивной заметки не стирает данные на Google Drive. Директория
заметки `<id>/` переименовывается в `~<id>/` и больше не попадает в
манифест синхронизации вместе со всеми вложениями. Для этого нужна новая
версия Web App с методом `delete`.

## Что попадает в манифест

В манифест входят только директории заметок с 32-символьным hex-ID и их
содержимое. Файлы и папки, начинающиеся с `.` или `~`, игнорируются.

## Ограничения

- Файлы больше 8 МБ не синхронизируются.
- Удаления не распространяются: локально отсутствующий файл будет скачан,
  удалённый на сервере — загружен заново.
- При одновременном изменении файла на двух устройствах побеждает более новая
  версия, а число конфликтов показывается в статусе.
- Apps Script имеет суточные квоты и ограничение времени выполнения около
  6 минут. Для обычной базы заметок этого достаточно; большие видео и
  архивы лучше хранить отдельно.
- Токен — это фактически пароль к вашему Web App. Не публикуйте ссылку
  с `drive_token`, используйте длинное случайное значение и при необходимости
  перевыпускайте его через свойство `SYNC_TOKEN`.

## Если приложение пишет «Не удалось подключиться к Apps Script»

Это таймаут iframe-моста: страница `Bridge.html` не загрузилась или не
отправила сообщение `ready`.

1. Откройте URL Web App в новой вкладке, добавив `?action=bridge`:

   ```text
   https://script.google.com/macros/s/.../exec?action=bridge
   ```

   Должна открыться страница **Notes Sync Bridge** со статусом **Connected**.
   Если открывается вход Google, 404 или ошибка скрипта — проблема в
   развёртывании, а не в приложении.

2. В Apps Script откройте **Развернуть → Управление развёртываниями**,
   нажмите на карандаш и выберите **Новая версия**. Просто сохранить проект
   недостаточно — Web App работает с опубликованной версией.

3. Проверьте настройки развёртывания:
   - **Execute as**: `Me`;
   - **Who has access**: `Anyone` (не «Anyone with Google account»).

4. Убедитесь, что в проекте есть файл `Bridge.html`, а в `Code.gs` —
   функция `doGet` с `XFrameOptionsMode.ALLOWALL`.

5. Скопируйте URL именно из **Web App** и убедитесь, что он заканчивается
   на `/exec`, а не на `/dev`.

6. Если страница моста открывается, но приложение всё равно не подключается,
   проверьте блокировку сторонних iframe/cookies в браузере или расширения
   приватности. Попробуйте открыть приложение в другом браузере.
